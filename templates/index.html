🔥 FWI Prediction Project

Welcome!

This project predicts the Fire Weather Index (FWI) using machine learning.

The model analyzes different weather and environmental conditions to estimate the potential risk of forest fires.

About the Project

The prediction model is built using Python and Scikit-learn and deployed using Flask.

Technologies Used

  • Python
  • Pandas
  • NumPy
  • Scikit-learn
  • Flask
  • Machine Learning

Goal: Use machine learning to predict fire weather conditions and help understand forest fire risk.
